# Python Project Template

A small starting point for Python projects using the version selected in
`.python-version`, `uv`, Ruff, pre-commit, and GitHub Actions.

## Getting started

1. Create a repository from this GitHub template.
2. Rename `python-project-template` in `pyproject.toml` and rename the
   `src/python_project_template/` package to match your project. Update its
   references in the example test and commands below as well.
3. Install the Python version listed in `.python-version` and
   [uv](https://docs.astral.sh/uv/).
4. From the repository root, install dependencies and Git hooks:

   ```powershell
   uv sync
   uv run pre-commit install
   ```

   `uv sync` updates the included `uv.lock` after project or dependency changes.
   Commit those updates; CI uses `uv sync --locked` to reject an outdated
   lockfile.

5. Copy `.env.example` to `.env` and fill in local values if your project
   needs environment variables.

`.python-version` selects the local and CI interpreter. `requires-python` in
`pyproject.toml` declares the minimum Python version supported by the package.

## Useful commands

```powershell
# Run the example program
uv run python -m python_project_template

# Run tests
uv run pytest

# Run all pre-commit checks on every tracked file
uv run pre-commit run --all-files
```

After installing the hook, pre-commit runs automatically on staged changes
before each commit. GitHub Actions runs the same pre-commit checks, including
Ruff, plus the test suite on every push and pull request. GitHub checks happen
after pushing; require the workflow as a branch protection status check if you
want GitHub to block merging changes when checks fail.

## Project layout

```text
src/python_project_template/  Application package
tests/                        Tests
.github/workflows/            Continuous integration
.pre-commit-config.yaml       Commit-time quality checks
pyproject.toml                Project and tool configuration
.python-version               Python version selected by uv
uv.lock                       Resolved dependency versions (generated by uv)
```
